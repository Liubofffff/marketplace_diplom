# Metabase Dashboard — Аналитика продаж

**Интерактивный дашборд для анализа продаж, эффективности ассортимента и клиентской аудитории.**

---

## О проекте

Проект представляет собой интерактивный аналитический дашборд в **Metabase**, построенный на данных о продажах.

Дашборд позволяет анализировать:

- ключевые показатели продаж;
- динамику выручки и количества проданных товаров;
- среднюю цену продажи;
- размер предоставленных скидок;
- эффективность товаров и клиентов;
- ассортимент с помощью **ABC-анализа по выручке**;
- частоту покупок клиентов;
- структуру клиентской аудитории по полу.

Данные хранятся в **PostgreSQL** в таблице `sales`.

SQL-запросы для визуализаций написаны на PostgreSQL и используются непосредственно в вопросах Metabase.

---

## Цели проекта

Основные задачи дашборда:

1. Оценить ключевые показатели продаж.
2. Отследить динамику выручки и количества проданных товаров.
3. Проанализировать изменение средней цены продажи и скидок.
4. Определить наиболее эффективные товары и клиентов.
5. Провести ABC-анализ ассортимента по выручке.
6. Оценить частоту покупок клиентов.
7. Сравнить клиентские сегменты по полу.
8. Объединить основные показатели продаж в едином интерактивном дашборде.

# Структура дашборда

## 1. Ключевые показатели продаж

Главная обзорная страница дашборда. Содержит основные KPI и графики, позволяющие быстро оценить состояние продаж.

### KPI

- **Общая выручка** — сумма `total_price` за выбранный период.
- **Выручка на клиента **— выручка в расчёте на одного уникального клиента.
- **Продано, шт.** — общее количество проданных единиц товара.
- **Общая сумма скидки** — сумма скидок с учётом количества проданных единиц.

### Графики

#### Динамика выручки и продаж, шт.

Комбинированный график, показывающий изменение:

- выручки;
- количества проданных единиц

по дням выбранного периода.

Позволяет отслеживать рост и снижение продаж и сравнивать динамику выручки с объёмом продаж.

#### Динамика средней цены продажи

Линейный график, показывающий изменение средней фактической цены одной проданной единицы товара.

Средняя цена рассчитывается по формуле:

```text
Средняя цена продажи = Выручка / Количество проданных единиц
```

#### ТОП-5 клиентов по выручке

Рейтинг клиентов с наибольшей суммой выручки за выбранный период.

#### Динамика средней скидки на единицу

Линейный график, показывающий изменение средней скидки на одну проданную единицу товара.

# 2. Эффективность продаж

Раздел предназначен для оценки эффективности товаров и клиентов.

### KPI

- **Средняя цена продажи**
- **Продано, шт.**
- **Уникальные клиенты**

Таблица товаров-лидеров по выручке.

| Показатель               | Описание                              |

Таблица позволяет определить товары, формирующие основную часть выручки.

# 3. ABC-анализ ассортимента

ABC-анализ используется для оценки вклада товаров в общую выручку.

Товары ранжируются по выручке от максимальной к минимальной, после чего рассчитывается накопленная доля выручки.

### Классификация

| Категория | Накопленная доля выручки |
| --------- | -----------------------: |
| **A**     |                   до 80% |
| **B**     |                   80–95% |
| **C**     |                более 95% |

### Интерпретация

- **A** — товары, формирующие основную часть выручки;
- **B** — товары со средним вкладом в выручку;
- **C** — товары с небольшим вкладом в общую выручку.

### Таблица ABC-анализа

| Показатель                   | Описание                      |
| ---------------------------- | ----------------------------- |
| **Товар**                    | `product_id`                  |
| **Выручка**                  | Выручка по товару             |
| **Накопленная доля выручки** | Накопительный процент выручки |
| **ABC-категория**            | A, B или C                    |

Для расчёта накопленной доли используются оконные функции PostgreSQL.

В дашборде предусмотрен фильтр по ABC-категории, позволяющий отдельно просматривать товары групп **A**, **B** или **C**.

# 4. Динамика и цены

Раздел предназначен для анализа изменения показателей продаж во времени.

### Динамика выручки и продаж по дням

Показывает:

- выручку за день;
- количество проданных единиц за день.

Используется для выявления периодов роста и снижения продаж.

### Продажи по дням недели

Позволяет сравнить продажи по дням недели:

- понедельник;
- вторник;
- среда;
- четверг;
- пятница;
- суббота;
- воскресенье.

График помогает определить дни с наиболее высокой и низкой активностью покупателей.

### Динамика средней цены продажи

Показывает изменение средней цены одной проданной единицы во времени.

Расчёт:

```text
Средняя цена продажи =
SUM(total_price) / SUM(quantity)
```

Показатель рассчитывается на основе фактической стоимости продаж после применения скидок.

# 5. Анализ клиентской аудитории

Раздел посвящён структуре клиентской базы и покупательскому поведению.

## Выручка по полу

Круговая/кольцевая диаграмма показывает распределение общей выручки между клиентами разного пола.

Позволяет оценить вклад каждой группы в общую выручку.

## Распределение клиентов по полу

Показывает количество уникальных клиентов в каждой категории пола.

Позволяет сравнить размер клиентских сегментов.

## Частота покупок клиентов

Клиенты распределяются по количеству покупок:

- **1 покупка**
- **2 покупки**
- **3+ покупок**

Для определения отдельного покупательского события используется комбинация:

```text
client_id + purchase_datetime
```

Таким образом, уникальная комбинация клиента и времени покупки рассматривается как отдельное покупательское событие.

> В таблице `sales` отсутствует отдельный `order_id`, поэтому показатель отражает количество покупательских событий, определённых по `client_id` и `purchase_datetime`, а не гарантированное количество оформленных заказов.

## Средняя выручка на клиента по полу

Показывает ARPC для каждой категории пола:

```text
ARPC = Выручка / Количество уникальных клиентов
```

Позволяет сравнить среднюю выручку на одного клиента в разных сегментах.

## Сводная статистика по полу

Таблица содержит основные показатели клиентской аудитории:

| Показатель                |
| ------------------------- |
| Пол                       |
| Выручка                   |
| Уникальные клиенты        |
| Продано, шт.              |
| Количество покупок        |
| Средняя цена продажи      |
| Средняя скидка на единицу |

# Фильтры дашборда

Для интерактивного анализа используются фильтры:

- **Дата покупки**
- **Товар**
- **Пол**
- **Клиент**
- **ABC-категория**

Фильтры позволяют анализировать как весь массив данных, так и отдельные сегменты.

---

# Источник данных

Основная таблица:

```text
sales
```

Основные поля:

| Поле                | Описание                      |
| ------------------- | ----------------------------- |
| `client_id`         | Идентификатор клиента         |
| `product_id`        | Идентификатор товара          |
| `gender`            | Пол клиента                   |
| `purchase_datetime` | Дата и время покупки          |
| `quantity`          | Количество проданных единиц   |
| `price_per_item`    | Цена единицы товара до скидки |
| `discount_per_item` | Скидка на единицу товара      |
| `total_price`       | Итоговая стоимость продажи    |

Итоговая стоимость продажи рассчитывается как:

```text
(price_per_item - discount_per_item) × quantity
```

# Используемые возможности SQL

В проекте используются:

- агрегатные функции `SUM()`, `COUNT()`, `AVG()`;
- `COUNT(DISTINCT ...)`;
- оконные функции `OVER()`;
- Common Table Expressions (`WITH` / CTE);
- `CASE`;
- `DATE()`;
- `DATE_TRUNC()`;
- `EXTRACT()`;
- `STDDEV_POP()` при расчёте статистических показателей;
- условные фильтры Metabase.

ABC-анализ реализован с использованием оконных функций для расчёта накопленной выручки и определения категории товара.

В результате создан единый интерактивный дашборд, объединяющий основные направления анализа продаж:
